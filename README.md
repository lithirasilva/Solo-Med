# 🏥 Clinic Management System

A comprehensive web application designed to streamline clinic operations, including appointment scheduling, patient management, and digital prescriptions.

## 🌟 Features

- 📅 **Appointment Management**: Allows patients to book, reschedule, or cancel appointments easily.
- 🩺 **Patient Records**: Stores and organizes patient information securely.
- 💊 **Digital Prescriptions**: Doctors can create, manage, and share prescriptions electronically.
- 📊 **Reports and Insights**: Generates reports for clinic activities and patient data.

---

## 🔧 Technologies Used

- **Frontend**: Vue.js, HTML, CSS, JavaScript
- **Backend**: Laravel (PHP)
- **Database**: MySQL
- **Additional Tools**: Laravel Inertia for a seamless SPA experience

## 🚀 Getting Started

### Prerequisites

Make sure you have the following installed:
- [Composer](https://getcomposer.org/)
- [Node.js](https://nodejs.org/)
- [XAMPP](https://www.apachefriends.org/index.html) or a similar local server
- Git

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/lithirasilva/Solo-Med.git

   ```
2. Navigate to the project directory:
   ```bash
   cd Solo-Med
   ```
3. Install PHP dependencies:
   ```bash
   composer install
   ```
4. Install JavaScript dependencies:
   ```bash
   npm install
   ```
5. Set up the environment:
   - Duplicate the `.env.example` file and rename it to `.env`.
   - Configure the database credentials in the `.env` file.
6. Run migrations to set up the database:
   ```bash
   php artisan migrate
   ```
7. Start the local server:
   ```bash
   php artisan serve
   ```
8. Access the application at:
   ```
   http://localhost:8000
   ```
